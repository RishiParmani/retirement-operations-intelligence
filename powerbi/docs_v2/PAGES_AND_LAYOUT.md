# Pages and layout

Canvas 1280 x 720 (page 3 is 1280 x 900). Header band navy `#0B1F3A`; canvas `#F4F6FA`; cards white with `#E2E8F0` border. Accents: blue `#2563EB`, teal `#0F9D8A` (good), orange `#F59E0B` (watch), red `#DC2626` (critical), slate `#64748B`. Font: Segoe UI.

Every page has: title and subtitle header, page navigator (top right), and a synced slicer strip (date range, region, operation type, priority, channel; page 2 adds status). Slicers are synchronised across all pages.

## 1. Executive Operations Overview
8 KPI cards (total, completed, pending, failed, avg hours, SLA compliance, exception rate, rework rate); monthly volume line; monthly SLA compliance line; operations by status; by priority; by region; by channel; live insights card.

## 2. Operational Performance Analysis
8 KPI cards (adds escalated, completion rate, avg SLA target); received vs completed per month; average hours and volume by operation type; average hours by region, priority and channel.

## 3. SLA & Operational Risk Analysis
7 KPI cards; SLA compliance by operation type, priority, region and month; exceptions by operation type and exception rate by region, priority, channel; rework rate by operation type, region, priority; "where to look first" insights card.

Value axes start at zero so that near-identical rates are not visually exaggerated.
